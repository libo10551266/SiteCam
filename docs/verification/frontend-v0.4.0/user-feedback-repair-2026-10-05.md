## 审核与验证方式

Android 与 HarmonyOS 按产品代码划分实施；设计资源与使用指南单独维护。实现完成后由 Astra 独立审核本轮改动，发现问题后修正并复审。

构建和设备验证串行执行，使用现有签名及连接设备。验证与本轮问题对应：静止定位、刷新状态转换、镜头倍率、横竖屏布局、样式确认按钮、功能指引与指南入口。设备结果、源码检查和构建结果分别记录。
