定位距离过滤的判断依据 Android [LocationManager](https://developer.android.com/reference/android/location/LocationManager) 与 Google [LocationRequest](https://developers.google.com/android/reference/com/google/android/gms/location/LocationRequest) 的公开最小距离语义。该判断是源码和 API 语义确认，不是本轮 Android 真机复现。

F7 初次实测中，主任务报告对话框根区域为 `[132,74][2400,1080]`，两个页脚可点击区域抵达屏幕底边，右按钮抵达屏幕右边；截图可见右侧和底部裁切。独立读取项目实际使用的 Compose UI 1.7.8 后确认：`usePlatformDefaultWidth=false` 会把父测量规格替换为 configuration 的整屏尺寸，并在布局后把窗口设为该子布局尺寸；平台给出的避开挖孔/系统栏后的约束因此未约束内容。修正使用 `true` 保留父测量规格，只对本 `DialogWindowProvider` 的窗口设置 MATCH_PARENT。稳定为 `true` 时参数更新与布局过程均不会覆盖该尺寸；共享 `AdaptivePaneLayout` 没有修改。
